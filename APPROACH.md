# Approach note (for the submission email)

I modelled every brand's process as its own operating calendar plus minimum-staffing rule, separate from each employee's schedule, and wrote a deterministic rule-based engine that plans weekly offs week by week (tightest-staffed employees first), then validates the result against a single rule set that both the generator and the manual editor share. Gaps that cannot be solved (a sole resource who is off or on leave) are never hidden: they are flagged as mandatory conflicts and the system simulates concrete resolutions (cross-cover, swap off, call-in with comp-off, standing backup, client exception) and shows what each would break before anything is applied. Changes after generation are previewed first and repaired minimally, so only the cells that must move are touched.
